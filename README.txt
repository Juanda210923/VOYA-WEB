VOYA — Sitio web turístico multipágina
======================================

Contenido:
- index.html: página de inicio
- explorar.html: catálogo de destinos
- destino.html: detalle demostrativo de Madrid
- ofertas.html: ofertas ilustrativas
- favoritos.html: favoritos de ejemplo
- login.html: interfaz de inicio de sesión
- soporte.html: soporte y contacto
- css/styles.css: hoja de estilos compartida y responsive

Uso:
1. Extrae la carpeta del ZIP.
2. Abre index.html en un navegador.
3. Navega mediante el menú superior.

Importante:
Es una maqueta académica estática construida con HTML y CSS. No implementa
autenticación, búsquedas dinámicas, reservas, favoritos persistentes, clima en
tiempo real ni envío de formularios. Precios, reseñas y contactos son ejemplos.
Las imágenes y fuentes externas requieren conexión a Internet.
